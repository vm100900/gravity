> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pencil strokes redraw slightly 8 times a second, cycling through 3 drawings, like a hand-drawn cartoon.

**Architecture:** `src/sketch.rs` keeps the current boil drawing in a `static AtomicU64`; the six stroke functions that consume a seed mix it in, so every stroke built on them boils. `Game::draw` picks the drawing from the clock once per frame.

**Tech Stack:** Rust, macroquad, `cargo test`; headless Chromium + playwright-core + pngjs in `/tmp/gravity-fs-test` (not committed).

Spec: `docs/superpowers/specs/2026-10-01-line-boil-design.md`

## Global Constraints

- Always on; 8 redraws per second (`BOIL_FPS = 8.0`); 3 drawings (`BOIL_DRAWINGS = 3`).
- Drawing 0 leaves every seed unchanged (today's look).
- Boil: every pencil stroke. Still: graph-paper grid, paper grain, text.
- The working tree has unrelated uncommitted changes (`web/index.html`, `.gitignore`); commit only the files this plan names.

```rust
// ---------------------------------------------------------------------------
// Line boil: strokes redraw a little, like a hand-drawn cartoon
// ---------------------------------------------------------------------------

/// How many times a second the strokes are redrawn.
const BOIL_FPS: f64 = 8.0;
/// How many different drawings the boil cycles through.
const BOIL_DRAWINGS: u64 = 3;

/// Which drawing of the boil loop is showing.
static BOIL: AtomicU64 = AtomicU64::new(0);

/// Which drawing of the boil loop to show at `time` (seconds).
pub fn boil_drawing(time: f64) -> u64 {
    (time * BOIL_FPS) as u64 % BOIL_DRAWINGS
}

/// `seed` as it is in boil drawing `drawing`; drawing 0 leaves it unchanged.
pub fn boil_seed(seed: u64, drawing: u64) -> u64 {
    seed ^ drawing.wrapping_mul(0x9E37_79B9_7F4A_7C15)
}

/// Picks the boil drawing for everything drawn from now on (once per frame).
pub fn set_boil(drawing: u64) {
    BOIL.store(drawing, Ordering::Relaxed);
}

/// `seed`, redrawn for the current boil drawing.
fn boiled(seed: u64) -> u64 {
    boil_seed(seed, BOIL.load(Ordering::Relaxed))
}
```
